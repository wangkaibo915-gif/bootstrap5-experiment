# Выборочная сборка Bootstrap 5

Node.js 22. Установка и запуск:

```sh
npm ci
npm start
npm run build
```

Демонстрация сетки сохранена в коммите и теге `demo-grid`. Итоговая страница находится в `app/index.html`. Для публикации в GitHub Pages выберите GitHub Actions в настройках Pages. Workflow собирает проект и загружает каталог `app`.
