# Журнал инструментов

Макет открыт в браузере Pixso. Цвета и размеры оценены визуально. Конфигурация Context7 и Pixso подготовлена в .codeassistant/mcp.json.

Вызовы MCP из SourceCraft и скриншоты таких вызовов отсутствуют. Для завершения экспериментальной части необходимо подключить Context7 в SourceCraft Code Assistant и запустить Pixso Desktop с локальным MCP. Затем следует получить документацию и параметры макета через MCP, проверить diff и приложить реальные скриншоты.

## Подготовка рабочего окружения

Расширение SourceCraft Code Assistant 0.11.172 установлено из Visual Studio Marketplace. Проект experiment открыт в VS Code, запуск авторизации привел на страницу проверки браузера Yandex Cloud. Сеанс расширения не подтвержден. Проверка локального адреса Pixso MCP завершилась отказом в соединении. Эти результаты относятся к настройке среды, а не к выполненным вызовам MCP.

## Выполненные обращения к Context7

В рабочей области experiment авторизация SourceCraft подтверждена ответом в чате. В режиме Architect выполнены три вызова Context7. resolve-library-id нашёл /twbs/bootstrap. Два вызова query-docs по /twbs/bootstrap/v5.3.3 вернули рекомендации по частичным Sass-импортам и точечному подключению Collapse. В проекте проверены порядок functions, переопределения, variables, variables-dark, maps, mixins, компоненты и прямой импорт bootstrap/js/dist/collapse. Снимок итогового ответа приложен к отчету.

Проверка документации webpack через Context7 и обращение к Pixso MCP остаются отдельными этапами. Адрес 127.0.0.1:3667 при повторной проверке не принимал соединение.

## Проверка webpack

В SourceCraft выполнены два вызова resolve-library-id для webpack и sass-loader, затем два query-docs для /websites/webpack_js. Проверены порядок выполнения загрузчиков справа налево и настройка filename в MiniCssExtractPlugin. В конфигурации проекта файл styles.css извлекается после Sass, PostCSS и css-loader. Снимок результата добавлен в отчёт.

Pixso Desktop запущен, пользователь вошёл в аккаунт. В клиенте открыт раздел черновиков. Целевой макет доступен для просмотра в веб-интерфейсе. В локальном клиенте он ещё не открыт, и endpoint 127.0.0.1:3667 не принимает соединение.

## Чтение дизайна через Pixso MCP

Файл Figma из материалов занятия импортирован в черновики Pixso Desktop. В открытом редакторе включён локальный сервер http://127.0.0.1:3667/mcp. После перезагрузки окна VS Code SourceCraft зарегистрировал сервер и выполнил fetch_context, get_top_level_frames, query_nodes, read_components и get_node_dsl в режиме Architect.

Страница FAQs Ui (0:1) содержит фрейм FAQs (1:58) и список из четырёх карточек. Открытая карточка (1:62) имеет размер 886 × 186 px, закрытая — 886 × 82 px. У открытого фона цвет #1C1A1A, радиус 12 px, обводка rgba(254,232,1,.22) толщиной 1 px. Для вопроса и ответа использован Nunito Medium 24 и 20 px. Числовые параметры получены из полного DSL. Снимок ответа сохранён в docs/pixso-mcp.jpg и добавлен в отчёт вместе с таблицей соответствия параметров макета и SCSS. На этапе чтения файлы сборки не изменялись.

## Применение параметров макета

В режиме Code SourceCraft изменил три файла SCSS. Подключение Bootstrap осталось выборочным, удалены повторные импорты. Настроены состояния карточек, размеры, интервалы и видимый фокус. Производственная сборка webpack прошла. Chrome подтвердил работу четырёх панелей, открытие одной панели за раз, управление Tab, Enter и Space и отсутствие горизонтальной прокрутки на 375 px. Внешние запросы относятся к загрузке Nunito.
